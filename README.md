# 匠行内容写作（jiangxing-writing）

读者线驱动的长文写作技能 + 三道闸门质检工具。治 AI 写文章的七大病症：没有读者线、段落没有"问题"、信息点当段落、选题没搜用户真问题、攻略黑话当人话、小标题自问自答、写完不回读。

## 它解决什么

AI 写的公众号文章常见死法：机械过渡、"漏口/口径"类黑话满天飞、假装自问自答的小标题、上下段脱节、按"我要说全"而不是"读者想知道什么"来写。本技能把一套经数百轮实战返工沉淀的写作方法 + 机械校验器封装成可复用的 Agent 技能，让任何 AI 写手按"读者决策线"写稿，并在交稿前用三道闸门自检：

1. **闸门 0 · 机械校验**（`scripts/article_qa.py`）：30+ 项 FAIL 级硬检查——标题六条（字数/主题词/零我/零日期/黑话/组内卖点不重复）、SEO（111–119 字含标点/2-gram 零重复）、小标题（禁自问自答/禁正文复读标签）、段落（≤120 中文字/分号限制/PPT 气口）、AI 高频词与黑话黑名单、施工标记、时效口径、括号 ≤3、破折号密度、跨篇逐字复读。FAIL>0 退出码返回 1，可直接接入 CI/自动化卡死。
2. **闸门 1 · LLM 裁判**：六组 30 条语义细则（标题人话/语体"你"贯穿/抽屉归属/口径四件套/主轴对账/红线清零），拦脚本拦不住的"像不像人话"。
3. **闸门 2 · 读者模型**：模拟零背景读者走三步（标题+首段三问 → 小标题拼成 reader journey → 数字可操作），拦所有规则没覆盖的新错型。

## 适用

## 安装（WorkBuddy / 支持 Agent Skills 的客户端）

将整个 `jiangxing-writing/` 目录放入技能目录（如 `~/.workbuddy/skills/`），或打包 zip 上传。

## 使用

对 Agent 说："用匠行内容写作，写一篇 ×× 主题的公众号文章" 或 "用三道闸门质检这篇稿子"。

机械校验器也可独立运行（无需 Agent）：

```bash
python scripts/article_qa.py 草稿.md --theme 新疆
# 可选：--minlen 2000 --maxlen 2500 --minbold 8 --swiss -o 报告.txt
```

`--theme` 任意主题词（新疆/瑞士/滑雪装备/装修均可），每条标题须含该主题词，无主题词拒检。

## 方法论内核

一切规则从一条元根因长出：**动笔第一问不该是"这个主题有哪些事实要写"（信息装配工），而是"读者是谁、他卡在哪个决策、最怕哪种失败、我替他拍哪个板"（决策顾问）。** 段落顺序跟着读者决策走，不跟着信息维度走。
