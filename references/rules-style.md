# 文风硬条（人话判据 / 去AI味 / 标点 / 人称）

> 去AI味不是文风偏好，是平台机检生存线：被识别出 AI 味＝限流。写的时候就回避，不是成稿后再修饰。

## 一、人话总判据

**这句话放饭桌上真有人这么讲吗？** 不会讲＝重写。配套**出声朗读测试**：读着拗口、装腔的地方，换成喝酒撸串时会说的话（"串上两三个点""这条线同样硬实"这类话真人聊天不会说）。
- 黑话/发明词清零（"漏口"→照样要花钱；"按攻略口径"→去过的人算过一笔账；"动线"→路线；"加分项"→顺路可以加）。
- 黑话/术语不默认读者懂：能铺垫绝不跳步。
- 超长专名（>7字）用简称；官方词换白话。
- 口语补全：按日常说话的语序、停顿、补语写，不书面腔改装（「最戳我的是」是半截话，人讲的是「真正戳中我的是，」）。
- 删词补偿：删绝对化词/夸张词必须同步补字保语感，禁只减不补。

## 二、去AI味六查（每篇交稿前逐查）

1. **节奏均匀＝头号特征**：连续 3 句长度接近、每段行数接近＝高危；长短句必须交错（<10 字短句与 >25 字长句混排），段落长短参差。连续 ≥3 个 ≤10 字短句各带句号成段（PPT 气口）＝提醒。
2. **排比密度**：连续两组以上「不是A而是B／不仅…还…／既…又…」＝高危；三段式列举改两项或四项。
3. **AI 高频词家族禁用**：标志着/彰显/赋能/格局/见证了/不仅仅是/深入探讨/值得注意的是/在这个…的时代/综上所述/令人叹为观止/独特的魅力/天花板/顶级/重新定义/史上最/首先/其次/此外/总之/再说。
4. **结构模板腔**：每段都是「观点+解释+例子」三件套＝高危；小标题句式同构＝高危；时代开场、展望收尾＝高危。
5. **标点与强调滥用**：破折号密度 <2/千字（每个破折号过三问：能断开？用句号。能插进去？用逗号。需要解释？用冒号）；「**XX：**」式内联列表＝机检特征；全文括号 ≤3 处且只装硬注释，禁「X（即Y）」式自我定义；叹号全文 ≤3；冒号只用于引出具体内容，禁制造「揭示感」。
6. **模糊归因**：「专家认为」「行业数据显示」不给出处＝高危；引概念前文须铺垫。

## 三、人称与画面

- 主语"你"贯穿对话体；开头有画面后面全客观＝退回。
- 人称双轨：参数段用"它/这X"，体验段换"你/我"且每 2–3 句一次；「你」只放动作前不放判断前（"你拉开窗帘"✓，"你值得拥有"✗）；"你"出现前须有人称铺垫，禁"你如果是"式突兀转人称。
- 单段「你」≥2＝堆人称嫌疑（脚本提醒）：人称要用在需要的地方，堆多了反而假。
- 体验段逐段对画面三件套：动作＋时间刻度＋身体感受，缺一样补一样。
- 段首必有主语；禁全客观说明文体。

## 四、数字与排版

- 正文数据统一阿拉伯数字、中文与数字间不加空格（36到66人）；同一句内禁中西数字混用；同一数据全篇同体例；惯用约数（三三两两/几十）保留中文。
- 关键数字后必跟一句人话翻译（80 配近 50→「一个人照看一个半客人」）。
- 标点停顿四级：顿号<逗号<分号<句号；一段内句号间距几乎相等＝机器节奏，退回重断；顿号只连并列词语，禁连句子；省略号与"等"不同用。

## 五、噪声预算

每千字允许保留 2–3 处轻度 AI 特征自然分布（一个工整排比、一个稍长过渡句）。全文零特征＝另一种整齐、一样可疑。去AI味不是清零，是自然分布。

## 六、终检动作

1. 出声读一遍（气口：无 PPT 段、不拗口）；随机抽 3–5 句自问：平时聊天会这么说吗？
2. 随机抽中间一段单独看：猜不出是 AI 写的才算过。
3. 形容词删除测试：删掉全文形容词，事实仍撑得住判断吗？撑不住＝回炉补事实。
4. 通读全文当一条流：①场景/时空有没有反复横跳 ②有没有凭空冒出的术语/数字/结论 ③前文立的指标/伏笔后文接住了吗。逐节孤立生成的文章每个模块都完整，但模块之间缺桥，读者就被甩下崖。
